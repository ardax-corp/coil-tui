# coil-tui

A component framework for terminal user interfaces in [Coil](https://github.com/ardax-corp/coil-lang), built on the `cli` package ([coil-cli](https://github.com/ardax-corp/coil-cli)).

Work in progress. The design, component model and plan are in [docs/design.md](docs/design.md).

## Development

`make test` runs the tests and `make fmt` checks formatting. Both expect
coil-stdlib and coil-cli checked out next to this repository, or their
`src` directories passed in `COIL_ROOTS`.
